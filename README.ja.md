# MultiMind — あなたの個性をマッピング（日本）

**あなたの内なる世界を統合するジャーナル。**

MultiMind は、あなたの考え、夢、人間関係を統合し、個性と心の風景の進化する地図へと変えるマルチジャーナルシステムです。複数のジャーナルタイプがあなたの内面のあらゆる側面を捉え、一つひとつの記録が分析され、結びついて、あなたの生きた肖像を形作ります。

## 特徴
- 考え、夢、人間関係などのためのマルチフォーマットジャーナル
- テーマ、ペルソナ、感情パターンをAIが抽出
- 体験同士のつながりを示すインタラクティブなマインドマップ
- 記録ごとに進化するパーソナリティ統合
- 気分トラッキングと感情分析
- プライバシーファースト — あなたのデータはあなたのもの
